# 📊 edFacts

An interactive, data-driven web application designed to explore, visualize, and analyze U.S. educational datasets. Built with **React** and powered by the **Urban Institute’s Education Data Portal API**, **edFacts** makes complex, longitudinal education metrics accessible and intuitive for researchers, educators, and the public.

🚀 **Live Demo:** [ed-facts.vercel.app](https://ed-facts.vercel.app/)  
📦 **Repository:** [github.com/Alex-is-Gonzalez/edFacts](https://github.com/Alex-is-Gonzalez/edFacts)

---

## 🌟 Overview

Educational datasets—spanning assessments, graduation rates, and demographic distributions—are often buried across complex government archives and massive tabular files. 

**edFacts** bridges this gap by offering a streamlined front-end interface that queries the Urban Institute's Education Data API in real-time. Users can filter, search, and view key educational indicators across schools, districts, and states without needing prior data-science or API querying experience.

---

## ✨ Features

- 🔍 **Interactive Data Querying:** Dynamic search and filtering by state, institution, year, and demographic indicators.
- 📈 **Data Visualization:** Clean visual breakdowns and summary metrics derived directly from official federal datasets (EDFacts / Common Core of Data).
- ⚡ **Responsive & Modern UI:** Optimized for seamless performance across mobile, tablet, and desktop screens.
- 🌐 **Direct API Integration:** Consumes RESTful endpoints asynchronously with client-side caching and error handling.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3 / Modern Styling
- **Data Source:** [Urban Institute Education Data Portal API](https://educationdata.urban.org/)
- **Hosting & Deployment:** [Vercel](https://vercel.com/)
- **Version Control:** Git & GitHub
